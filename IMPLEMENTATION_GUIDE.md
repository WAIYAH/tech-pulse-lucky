     TRUST

**Keep these three in balance:**

- **Revenue:** Sustainable, funds operations

## Decision Framework

When someone asks "Should we build X?" use this framework:

```
1. Does it help users achieve their job-to-be-done?
   No → Don't build
   
2. Can we build it in <1 week?
   No → Postpone
   
3. Does it require users to create accounts or install apps?
   Yes → Don't build
   
4. Will it increase trust or monetization?
   No → Don't build
   
5. Can we delete it later without breaking anything?
   No → Don't build
   
6. Does it conflict with our simplicity promise?
   Yes → Don't build
   
If all pass → Build it
```

**Examples:**

❌ **User Dashboard**
- ❌ Does NOT help JTBD (can learn without account)
- ❌ Takes 2+ weeks
- ❌ Requires accounts
- Result: Don't build

✅ **Email Autoresponder**
- ✅ Helps JTBD (don't miss webinar)
- ✅ Takes 3 days
- ✅ No account needed
- ✅ Increases revenue
- Result: Build

❌ **Mobile App**
- ❌ Doesn't help JTBD (website works on mobile)
- ❌ Takes 3+ months
- ❌ Requires app installation
- Result: Don't build

✅ **Certificates**
- ✅ Helps JTBD (prove learning)
- ✅ Takes 2 days
- ✅ No account needed
- ✅ Increases sharing/referrals
- Result: Build
